# Git Conventions Rules

Use the `git-prepare` skill when creating branches, syncing branches, preparing commits, writing commit messages, or preparing PRs.

Project policy: sync shared branches with merge, not rebase. Do not rewrite shared branch history.

Commit format: `type: message` — lowercase type (`feat`/`fix`/`refactor`/`test`/`docs`/`style`/`chore`/`perf`/`ci`/`build`), imperative mood, ≤50 chars, no trailing period.
